# Three-minute demo script

1. **Problem (20s):** show the stale `Purchasing` locator and explain that Odoo is unmodified customer software.
2. **Boundary (20s):** show cloud/edge diagram; point out that credentials and raw trace stay on edge.
3. **Failure (30s):** queue a run, let Playwright fail, open the timeline and local trace.
4. **Diagnosis (40s):** show failure class, candidate score components, confidence and evidence. Contrast a unique candidate with the ambiguous fixture that abstains.
5. **Safety (40s):** open the constrained locator patch; point out retained assertions and lack of arbitrary code.
6. **Validation (30s):** run three restored-snapshot attempts; show that approval is unavailable beforehand.
7. **Human decision (20s):** approve v2, queue a passing run, then demonstrate rollback.
8. **Honesty (20s):** show the case study, test output and uncompleted real-user pilot section.
